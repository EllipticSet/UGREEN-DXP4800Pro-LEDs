**UGREEN DXP4800 Pro LEDs**

Control the Power, LAN and four drive-bay LEDs of the UGREEN DXP4800 Pro running Unraid. Set colours, disk activity pulses and standby breathing in the WebGUI. Preview LED colours and brightness on the front-panel image, with Test buttons for connectivity and SMART warning colours. Tests affect only the image; Apply updates the physical LEDs.

Configure the plugin in **Settings → LED Settings**. Requires Unraid 7.3.2+ and a matching bundled module for kernel 6.18.38-Unraid or 6.18.54-Unraid. Support: GitHub Issues.
