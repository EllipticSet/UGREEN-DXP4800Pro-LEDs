# Security policy

## Supported versions

Security fixes target the latest stable plugin release. Older releases and development builds do not have a separate security maintenance commitment. Use the supported NAS model and kernels listed in the [README](README.md).

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/EllipticSet/UGREEN-DXP4800Pro-LEDs/security/advisories/new), available under **Security → Advisories → Report a vulnerability**.

Include the affected plugin, Unraid and kernel versions, the vulnerable component, reproduction steps, prerequisites and potential impact. A minimal proof of concept is helpful. Remove credentials and private information from attachments.

Do not publish exploit details in a public issue or pull request while a report is being assessed. Ordinary bugs and feature requests belong in [Issues](https://github.com/EllipticSet/UGREEN-DXP4800Pro-LEDs/issues).

Reports are reviewed as time permits. Updates and any disclosure plan will be discussed in the private report; no fixed response or remediation deadline is promised.

## Scope

This repository includes privileged installation scripts, a monitor, WebGUI settings and bundled dependencies. Reports affecting these components are welcome. Issues in Unraid itself or unrelated plugins should be reported to their respective projects.
